# 电商销售分析与用户RFM分层

基于106万条电商交易记录，完成商品销售趋势、库存周转ABC分析、
用户RFM分层及差异化运营策略输出，为选品备货和精准营销提供数据支撑。

---

## 项目概况

| 项目 | 详情 |
|------|------|
| 数据集 | Online Retail II（106万条，2009-2011） |
| 技术栈 | Python / pandas / matplotlib / seaborn |
| 分析方法 | ABC分类法 / RFM模型 / 时间序列分析 |
| 客户数量 | 5,878名 |
| 商品SKU | 4,631个 |
| 总销售额 | £17,743,429 |

## 核心发现

### 商品销售分析

| 发现 | 数据支撑 | 业务建议 |
|------|----------|----------|
| 销售额季节性显著 | Q4每年大幅攀升，圣诞前达峰值 | Q4旺季前2个月提前备货 |
| A类商品高度集中 | 21.3%的SKU贡献80%销售额 | 优先保障A类库存，降低C类占比 |
| 销售峰值时间明确 | 周四上午10-11点为最高峰 | 选择该时段推送促销活动 |
| 英国本土主导 | 英国销售额远超其他国家 | 重点维护英国市场供应链 |

### 用户RFM分层结果

| 用户层 | 人数 | 占比 | 平均消费额 | 核心策略 |
|--------|------|------|-----------|----------|
| 高价值用户 | 1,300 | 22.1% | £9,329 | VIP专属权益+优先客服 |
| 忠诚用户 | 621 | 10.6% | £1,049 | 会员积分+专属折扣 |
| 流失高价值用户 | 824 | 14.0% | £1,983 | 个性化召回券+电话回访 |
| 新用户/潜力用户 | 828 | 14.1% | £725 | 首购优惠+新手引导 |
| 流失用户 | 1,523 | 25.9% | £438 | 低成本EDM测试 |
| 一般用户 | 782 | 13.3% | £2,637 | 常规促活推送 |

> 流失高价值用户（824人）是召回优先级最高的群体：曾经平均消费£1,983，
> 但已平均369天未购买，个性化召回ROI最高。
